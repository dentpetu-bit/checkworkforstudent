# Student Score Checker — Kru Dew

เว็บสำหรับให้นักเรียนตรวจสอบคะแนนจาก Supabase Project เดียวกับ QR Score Studio

## ไฟล์
- `index.html` หน้าเว็บ
- `styles.css` รูปแบบหน้าตา Responsive
- `app.js` ค้นหานักเรียนและโหลดคะแนนแบบอ่านอย่างเดียว
- `config.js` การเชื่อมต่อ Supabase เดิม

## การทำงาน
1. นักเรียนกรอกรหัสนักเรียน
2. ระบบค้นหาจากตาราง `students`
3. โหลดชิ้นงานของห้องจาก `assignments`
4. โหลดคะแนนเฉพาะนักเรียนคนนั้นจาก `scores`
5. ปุ่ม `ก่อนกลางภาค` ใช้ `period = pre`
6. ปุ่ม `หลังกลางภาค` ใช้ `period = post`

คะแนนที่ยังไม่มี row ใน `scores` จะแสดงเป็น `— / ยังไม่บันทึก`
คะแนน 0 ที่ถูกบันทึกจริงจะแสดงเป็น `0`

## วิธีนำขึ้น GitHub Pages
สร้าง repository/folder ใหม่ แล้วอัปโหลด 4 ไฟล์หลัก (`index.html`, `styles.css`, `app.js`, `config.js`) จากนั้นเปิด GitHub Pages ได้ทันที

## หมายเหตุด้านความปลอดภัย
ตัวเว็บใหม่นี้มีเฉพาะคำสั่ง SELECT และไม่มีปุ่มหรือโค้ดแก้ไขคะแนน แต่ Supabase RLS ของโปรเจกต์เดิมอนุญาต anon key อ่าน/เขียนตาม schema เดิม หากต้องการล็อกฐานข้อมูลจริงควรแยกสิทธิ์เว็บครูกับเว็บนักเรียนด้วย Supabase Auth/RLS เพิ่มเติม
