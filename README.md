# Student Score Checker v2

เว็บนักเรียนแบบอ่านข้อมูลจาก Supabase เดียวกับ QR Score Studio v36 แสดง 5 หมวด: ก่อนกลางภาค (`pre`), กลางภาค (`mid`), หลังกลางภาค (`post`), ปลายภาค (`final`) และเวลาเรียนจาก `attendance`.

## วิธีติดตั้ง
อัปโหลดไฟล์ทั้ง 4 ไฟล์ (`index.html`, `styles.css`, `app.js`, `config.js`) ในโฟลเดอร์นี้ไปยัง repository/folder ของ **เว็บนักเรียน** บน GitHub Pages โดยไม่ต้องแทนไฟล์ของเว็บครู และเปิดใหม่ด้วย hard refresh.

ระบบไม่แก้ฐานข้อมูล ไม่ต้องรัน SQL เพิ่ม หากมี schema v35/v36 อยู่แล้ว. `0` คือคะแนนที่บันทึกจริง; `—` คืองานที่ยังไม่ได้บันทึก. รายงานเวลาเรียนนับวันที่มี record ของห้อง และถือว่านักเรียนที่ไม่มี record ในวันนั้นเป็นขาดเช่นเดียวกับเว็บครู.

**ข้อจำกัดด้านความปลอดภัย:** การกรอกรหัสนักเรียนไม่ใช่การยืนยันตัวตน และ Supabase RLS ของ schema ที่ส่งมายังเปิดสิทธิ์ anon กว้าง จึงยังไม่รับประกันว่านักเรียนเห็นเฉพาะข้อมูลตนเองในเชิงสิทธิ์ฐานข้อมูล หากจะเผยแพร่สู่สาธารณะควรเพิ่ม authentication และจำกัด RLS ฝั่งเซิร์ฟเวอร์ก่อน. เว็บนี้ไม่มีคำสั่งเขียนคะแนน.
